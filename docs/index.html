The roadmap prioritizes a dependable Windows desktop experience, local file access and practical compatibility before adding advanced features.

Offline-first foundationCore editing should work without an internet connection.
Open document formatsODF support and carefully tested interoperability with common office formats.
One consistent experienceShared interface patterns, keyboard shortcuts, themes and recovery workflows.
Optional AI assistancePlanned provider integrations, with user-controlled configuration.

Honest progress, visible work.

BanaOffice is currently a source-code fork and engineering project, not a finished downloadable office suite. Features and release claims will be updated as they are implemented and verified.

Current state: Repository foundation, project documentation and development-check automation are being prepared. Full BanaOffice branding across the desktop applications, validated Windows installers, and end-to-end document compatibility remain unfinished.
